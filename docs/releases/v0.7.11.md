# MagicMD v0.7.11

v0.7.11 修复微信公众号代码块使用 `<br>` 表示换行时，代码被拼接成单行的问题。

## 代码块换行

- 保留 `<pre><code>` 内显式 `<br>` 表示的换行与空行。
- 支持 mdnice 等编辑器生成的嵌套语法高亮元素。
- 不在相邻高亮元素之间添加多余换行。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.11
```

验证 Python CLI：

```bash
uvx --from "magicmd==0.7.11" magicmd --version
```

# MagicMD v0.7.11

v0.7.11 fixes WeChat code blocks being collapsed into a single line when their source uses `<br>` elements for line breaks.

## Code Block Line Breaks

- Preserves explicit line breaks and blank lines represented by `<br>` inside `<pre><code>`.
- Supports nested syntax-highlighting elements generated by editors such as mdnice.
- Does not insert extra line breaks between adjacent highlighting elements.

## Install or Upgrade

```bash
uv tool install --upgrade magicmd
# or
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.11
```

Verify the Python CLI:

