# MagicMD v0.7.12

v0.7.12 补齐微信公众号原生代码片段中的 `<br>` 换行保留，避免 `.code-snippet__fix` 代码块仍被拼接成单行。

## 微信代码片段换行

- `.code-snippet__fix` 与普通 `<pre><code>` 统一使用同一套代码文本提取逻辑。
- 保留显式 `<br>` 表示的换行与空行。
- 继续保留 NBSP、命令边界和语法高亮节点的既有规范化行为。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.12
```

验证 Python CLI：

```bash
uvx --from "magicmd==0.7.12" magicmd --version
```

# MagicMD v0.7.12

v0.7.12 preserves `<br>` line breaks in native WeChat code snippets, preventing `.code-snippet__fix` blocks from still collapsing into a single line.

## WeChat Code Snippet Line Breaks

- Shares one code-text extraction path between `.code-snippet__fix` and regular `<pre><code>` blocks.
- Preserves explicit line breaks and blank lines represented by `<br>`.
- Keeps existing normalization for NBSP, command boundaries, and syntax-highlighting nodes.
