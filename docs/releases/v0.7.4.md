# MagicMD v0.7.4

v0.7.4 是一个采集质量补丁版本，重点修复源文章标题层级不连续时生成的 Markdown 目录出现断层的问题。

## 标题层级修复

- 修复源 HTML 从 `h2` 直接跳到 `h4`、`h5` 等更深层级时，Markdown 同样跳级的问题。
- 标题标准化现在按正文结构逐级建立层级：保留父子、同级和返回上级的关系，同时压平源 HTML 中缺失的中间层级。
- `h2 → h4 → h5` 现在会转换为 `## → ### → ####`，正常的 `h2 → h3 → h4` 保持不变。
- 保留原有的正文起始层级和编号标题识别规则，避免修复断层时改变既有文章结构。
- 增加微信公众号回归测试，覆盖真实文章中二级标题后直接出现四级标题的场景。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.4
```

验证 Python CLI：

```bash
uvx --from "magicmd==0.7.4" magicmd --version
```

# MagicMD v0.7.4

v0.7.4 is an ingestion-quality patch release focused on preventing gaps in generated Markdown outlines when source articles use discontinuous heading levels.

## Heading Hierarchy Repair

- Fixed Markdown heading jumps when source HTML moves directly from `h2` to `h4`, `h5`, or deeper levels.
- Heading normalization now builds the article outline one level at a time, preserving parent, sibling, and ancestor relationships while closing gaps in the source hierarchy.
- `h2 → h4 → h5` now becomes `## → ### → ####`, while a valid `h2 → h3 → h4` hierarchy remains unchanged.
- Preserved the existing body-start depth and numbered-heading detection rules so the repair does not change established article structures.
- Added a WeChat regression case for an article where a fourth-level heading appears directly after a second-level heading.
