# MagicMD v0.8.0

2026-11-05

v0.8.0 新增离线 HTML 解析与 Markdown 修复接口，并将核心解析依赖与命令行、浏览器组件分开安装。

## 离线核心接口

- `parse_html(html, url)` 将调用方提供的 HTML 转为 `Article`，包含 Markdown 正文、标题、作者、来源与图片信息。
- `repair_markdown(markdown)` 可单独修复 Markdown 排版，保护行内代码和代码块。
- 两个接口均不联网、不下载媒体、不写文件；基础包仅依赖 Beautiful Soup、markdownify 与 Pydantic。

```bash
pip install "magicmd==0.8.0"
```

```python
from magicmd import parse_html, repair_markdown

article = parse_html(html, "https://example.org/article")
markdown = repair_markdown(article.content_markdown)
```

## CLI、Studio 与升级

从 0.7.x 升级并继续使用 CLI 或 Studio 时，需要显式安装命令行与浏览器依赖：

```bash
uv tool install --upgrade "magicmd[cli,browser]==0.8.0"
# 或
pipx install --force "magicmd[cli,browser]==0.8.0"
# npm 安装方式保持不变，需要本机可使用 uvx
npm install -g magicmd@0.8.0
```

npm 入口会自动选择同版本 Python 包及完整依赖。只需 HTTP 转换和命令行时可选择 `magicmd[cli]`。

- 修复安装后的命令行启动问题，缺少 CLI 依赖时给出安装提示。
- 修复 npm 发布检查的依赖选择，并补充安装后核心接口与 CLI 的验证。

CLI 版本检查：

```bash
magicmd --version
```

# MagicMD v0.8.0

2026-11-05

v0.8.0 adds offline HTML parsing and Markdown repair APIs and separates the core parsing dependencies from CLI and browser components.

## Offline Core APIs

- `parse_html(html, url)` converts caller-supplied HTML into an `Article` with Markdown content, title, author, source and image metadata.
- `repair_markdown(markdown)` repairs Markdown formatting while preserving inline and fenced code.
- Neither API fetches URLs, downloads media or writes files. The base package depends only on Beautiful Soup, markdownify and Pydantic.

```bash
pip install "magicmd==0.8.0"
```

```python
from magicmd import parse_html, repair_markdown

article = parse_html(html, "https://example.org/article")
markdown = repair_markdown(article.content_markdown)
```

## CLI, Studio and Upgrades

When upgrading from 0.7.x to keep using the CLI or Studio, explicitly install the CLI and browser dependencies:

```bash
uv tool install --upgrade "magicmd[cli,browser]==0.8.0"
# or
pipx install --force "magicmd[cli,browser]==0.8.0"
# The npm installation command stays the same; uvx must be available locally.
npm install -g magicmd@0.8.0
```

The npm wrapper selects the matching Python package version and complete dependencies automatically. Use `magicmd[cli]` if you only need HTTP conversion and the CLI.

- Fixed CLI startup after installation and added an installation hint when CLI dependencies are missing.
- Fixed dependency selection in npm release checks and added installed-package checks for the core APIs and CLI.

Check the CLI version:

```bash
magicmd --version
```
