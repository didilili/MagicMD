# MagicMD v0.7.15

v0.7.15 修复微信公众号“新智元”章节模板中的装饰图未过滤、完整标题退化成一至两行普通加粗的问题。

## 微信章节标题模板

- 识别 112×59 章节标记图和紧随其后的一至两行居中、19px 粗体标题。
- 过滤不承载正文信息的章节标记图，并将视觉换行合并为一个规范二级标题。
- 兼容微信原文中附带的无来源空图片占位节点。
- 清理只含 `<br>` 的空标题，避免生成裸 `##`。
- 继续保留同尺寸的有意义图片，以及没有章节标记图的普通居中加粗文字。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.15
```

验证 Python CLI：

```bash
uvx --from "magicmd==0.7.15" magicmd --version
```

# MagicMD v0.7.15

v0.7.15 fixes New Zhiyuan WeChat chapter templates whose decorative image was retained and whose complete heading degraded into one or two plain bold lines.

## WeChat Chapter Heading Template

- Detects a 112×59 chapter mark followed by one or two centered, bold 19px heading lines.
- Filters the non-content chapter mark and merges visual line wrapping into one normalized level-two heading.
- Tolerates source-less empty image placeholders inserted by WeChat.
- Removes headings containing only `<br>` so they do not produce a bare `##`.
- Preserves meaningful same-size images and ordinary centered bold text without the chapter mark.
