# MagicMD v0.7.3

v0.7.3 是一个采集质量补丁版本，重点修复微信公众号正文标题误判，以及图片、加粗文本和行内代码交界处的 Markdown 边界问题。

## 微信正文标题修复

- 识别正文区域中视觉上采用普通字号、常规字重和正文颜色的 `h1` 标签，并在标题层级标准化前将其还原为段落。
- 保留采用真实标题样式的 `h1`，避免为了修复特定文章而无条件移除一级标题。
- 修复普通正文被转换为 `##` 并进入文章目录的问题，同时恢复后续真实标题的正确层级。
- 增加微信公众号真实排版结构回归测试，覆盖普通正文 `h1`、真实一级标题和后续二级标题并存的场景。

## Markdown 边界修复

- 保留图片两侧相邻加粗文本的强调边界，避免图片分块后破坏前后文字格式。
- 清理独立成行的 `**` 标记，防止游离强调符号进入渲染结果。
- 调整行内代码掩码，避免合法的加粗文本与行内代码组合触发强调边界或未平衡标记误报。

## 安装或升级

```bash

```

验证 Python CLI：

# MagicMD v0.7.3

v0.7.3 is an ingestion-quality patch release focused on false WeChat body headings and Markdown boundaries around images, strong text, and inline code.

## WeChat Body Heading Repair

- Detected `h1` elements inside article bodies that visually use regular body size, weight, and color, and restored them to paragraphs before heading-depth normalization.
- Preserved `h1` elements with genuine heading typography instead of unconditionally removing all first-level headings.
- Prevented ordinary prose from becoming `##` entries in the article table of contents while restoring the correct depth of later genuine headings.
- Added a WeChat regression case covering visually plain body `h1` elements alongside a genuine first-level heading and a following second-level heading.

## Markdown Boundary Repair

- Preserved emphasis boundaries when images appear between adjacent strong spans.
- Removed standalone `**` markers before they reach renderers.
- Adjusted inline-code masking so valid combinations of strong text and inline code no longer trigger false strong-boundary or unbalanced-emphasis findings.
