# MagicMD v0.7.8

v0.7.8 补齐微信公众号章节序号的另一种富文本边界：两位序号被粘连在前一张图片说明末尾。

## 图片说明后的章节序号修复

- `AA 排名04` 后紧邻标题时，现在规范化为图片说明 `AA 排名` 和标题 `## 04 标题`。
- 同样覆盖 `06`、`07`、`08` 等两位章节序号，保留原有标题层级。
- 规则仅作用于“图片块、无空格两位后缀、紧邻标题”的组合。
- `年度报告2026`、`图 24` 等年份或普通图片编号保持不变。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.8
```

验证 Python CLI：

```bash
uvx --from "magicmd==0.7.8" magicmd --version
```

# MagicMD v0.7.8

v0.7.8 covers another WeChat numbered-section boundary where a two-digit section number is attached to the preceding image caption.

## Section Numbers After Image Captions

- When `AA Ranking04` is immediately followed by a heading, it is normalized into the caption `AA Ranking` and heading `## 04 Heading`.
- The same repair covers other two-digit section numbers such as `06`, `07`, and `08` while preserving the original heading level.
- The rule only applies to an image block, an unspaced two-digit caption suffix, and an immediately following heading.
- Years such as `Annual Report 2026` and ordinary spaced figure numbers such as `Figure 24` remain unchanged.
