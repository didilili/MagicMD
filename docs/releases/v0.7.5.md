# MagicMD v0.7.5

v0.7.5 是一个采集质量补丁版本，重点修复源网页将列表语义与可视列表标记重复编码时，生成的 Markdown 出现双重圆点或双重序号的问题。

## 列表标记修复

- 当 `ul > li` 的文本仍以 `•`、`●`、`○`、`◦`、`▪` 或 `▫` 开头时，MagicMD 现在会在 HTML 转换阶段移除这个重复的可视圆点，只保留标准 Markdown 列表标记。
- 当 `ol > li` 的文本序号与 HTML 列表的实际序号一致时，移除重复的 `1.`、`2、` 等文本前缀；不匹配的序号保持不变。
- 清理只作用于真实列表项的起始文本，不全局改写 Markdown，并避开行内代码、代码块和嵌套列表。
- 质量报告新增 `duplicate_list_marker`，能识别已有 Markdown 中的 `- •`、`- ●`、`1. 1.` 和同类重复标记。
- 新增无序列表、有序列表、行内代码保护和质量检测回归测试。

# MagicMD v0.7.5

v0.7.5 is an ingestion-quality patch release focused on duplicate bullets and numbers in generated Markdown when source pages encode both semantic list structure and visible list markers.

## Duplicate List Marker Repair

- When `ul > li` text still starts with `•`, `●`, `○`, `◦`, `▪`, or `▫`, MagicMD now removes that redundant visible bullet during HTML conversion and keeps only the standard Markdown list marker.
- When an `ol > li` text prefix matches the actual HTML list ordinal, duplicate prefixes such as `1.` or `2、` are removed; nonmatching numbers remain unchanged.
- Cleanup is limited to the leading text of real list items. It does not globally rewrite Markdown and avoids inline code, code blocks, and nested lists.
- Quality reports now include `duplicate_list_marker` for existing Markdown containing `- •`, `- ●`, `1. 1.`, and equivalent duplicate markers.
- Added regressions for unordered lists, ordered lists, inline-code protection, and quality detection.
