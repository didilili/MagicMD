# MagicMD v0.7.9

v0.7.9 补齐重复列表标记质量检测中的无空格边界，便于采集系统统一发现并修复历史文章中的异常列表。

## 重复列表标记检测

- 现在可识别 `- •正文`、`- •\`行内代码\``、`1. 1.正文`和`2. 2．正文` 等无空格写法。
- 有空格的 `- • 正文` 和 `1. 1. 正文` 继续正常识别。
- 普通段落、行内代码、代码块及嵌套列表中的合法符号不会被误报。

# MagicMD v0.7.9

v0.7.9 covers no-whitespace boundaries in duplicate-list-marker quality detection so ingestion systems can consistently find and repair malformed lists in stored articles.

## Duplicate List Marker Detection

- Detects no-space forms such as `- •text`, `- •\`inline code\``, `1. 1.text`, and `2. 2．text`.
- Existing spaced forms such as `- • text` and `1. 1. text` remain supported.
- Valid symbols in regular paragraphs, inline code, fenced code blocks, and nested lists are not reported.
