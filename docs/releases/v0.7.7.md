# MagicMD v0.7.7

v0.7.7 是章节标题格式修复版本，解决微信公众号文章中的独立章节序号没有并入相邻标题的问题。

## 章节序号标题修复

- `01`、`02` 等独立数字段落紧邻已识别的 Markdown 标题时，现在会合并为 `## 01 标题`。
- 合并会保留原有标题层级；标题已经包含相同序号时不会重复添加。
- 规则只处理一至两位的独立数字段落，不会改写 `2026` 等普通数字内容。
- 新增微信公众号富文本回归测试，覆盖正常合并、重复编号保护和非目标数字段落。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.7
```

验证 Python CLI：

```bash
uvx --from "magicmd==0.7.7" magicmd --version
```

# MagicMD v0.7.7

v0.7.7 is a section-heading formatting patch that merges standalone WeChat section numbers into their adjacent detected headings.

## Numbered Section Heading Repair

- Standalone numeric blocks such as `01` and `02` are now merged with an immediately following Markdown heading as `## 01 Heading`.
- The merge preserves the original heading level and does not duplicate a number already present in the heading.
- Only standalone numbers with one or two digits are handled, leaving ordinary numeric content such as `2026` unchanged.
- Added WeChat rich-text regressions for normal merging, duplicate-number protection, and non-target numeric paragraphs.
