# MagicMD v0.7.6

v0.7.6 是列表格式修复的补丁版本，补齐可视列表标记与正文之间没有空格时的转换边界。

## 无空格列表前缀修复

- `ul > li` 以 `•JSON`、`●Claude Code` 等形式开头时，现在会移除重复的可视圆点，只保留标准 Markdown 列表标记。
- `ol > li` 以 `2、Codex`、`3.内容` 等形式开头且序号与实际列表项一致时，现在会移除重复的文本序号。
- 清理仍只作用于真实列表项的起始文本，不全局改写 Markdown，也不会处理普通段落、行内代码、代码块或嵌套列表中的合法标记。
- 新增无空格无序列表和有序列表回归测试。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.6
```

验证 Python CLI：

```bash
uvx --from "magicmd==0.7.6" magicmd --version
```

# MagicMD v0.7.6

v0.7.6 is a list-formatting patch release that covers visible list markers directly adjacent to item text without whitespace.

## No-Space List Prefix Repair

- When `ul > li` text starts with forms such as `•JSON` or `●Claude Code`, MagicMD now removes the redundant visible bullet and keeps only the standard Markdown list marker.
- When `ol > li` text starts with forms such as `2、Codex` or `3.Content` and the number matches the actual list ordinal, MagicMD now removes the redundant textual number.
- Cleanup remains limited to the leading text of real list items. It does not globally rewrite Markdown or alter valid markers in regular paragraphs, inline code, code blocks, or nested lists.
- Added regression coverage for unordered and ordered list prefixes without whitespace.
