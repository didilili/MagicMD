# MagicMD v0.7.14

v0.7.14 修复微信公众号引用卡片中的微型装饰图被转换成独立正文图片的问题。

## 微信微型装饰图

- 识别自然尺寸仅 24–28px、位于显式微型布局容器中的开引号、小三角和闭引号素材。
- 仅过滤具有微信正文图片类、无有效替代文本且不属于链接内容的图片。
- 继续保留有意义的小图片、链接图标、普通正文图片和自然大图。
- 增加真实引用卡片结构回归测试与小链接图片保护测试。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.14
```

验证 Python CLI：

```bash
uvx --from "magicmd==0.7.14" magicmd --version
```

# MagicMD v0.7.14

v0.7.14 fixes tiny decorative images in WeChat quote cards being converted into standalone content images.

## WeChat Tiny Decorations

- Detects 24–28px opening quotes, triangles, and closing quotes inside explicit tiny layout boxes.
- Filters only WeChat content images with no meaningful alt text that are not linked content.
- Preserves meaningful small images, linked icons, regular content images, and naturally large images.
- Adds a regression fixture based on the real quote-card structure plus protection for small linked images.
