# MagicMD v0.7.10

v0.7.10 修复微信公众号使用可滚动样式模拟提示词或长文本面板时，面板边界在 Markdown 中丢失的问题。

## 滚动文本面板

- 识别固定高度、垂直滚动且带 `data-autoskip` 标记的微信公众号纯文本容器。
- 将面板正文转换为 `text` 围栏代码块，保留段落空行，避免内容与后续正文混在一起。
- 保留面板标题或说明文字，不把它们写入代码块。
- 排除包含图片、视频、表格和已有代码结构的容器，普通滚动布局与滚动图片不会被误判。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.10
```

验证 Python CLI：

```bash
uvx --from "magicmd==0.7.10" magicmd --version
```

# MagicMD v0.7.10

v0.7.10 fixes lost panel boundaries when WeChat articles implement prompts or long-form text panels with scrollable styles instead of semantic code markup.

## Scrollable Text Panels

- Detects fixed-height, vertically scrollable, text-only WeChat containers marked with `data-autoskip`.
- Converts panel content to fenced `text` blocks while preserving paragraph spacing and separation from following prose.
- Keeps panel titles or labels outside the fence.
- Excludes containers with images, video, tables, or existing code structures so ordinary scrolling layouts and scrollable images remain unchanged.
