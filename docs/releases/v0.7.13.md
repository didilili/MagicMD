# MagicMD v0.7.13

v0.7.13 修复微信公众号使用嵌套 `span` 样式表达章节层级时，视觉标题被转换成普通加粗的问题。

## 微信视觉标题

- 读取独占文本块内部覆盖完整标题文字的字号、颜色和字重样式。
- 将 20px 及以上的章节标题转换为二级 Markdown 标题。
- 将 17–19px 的粗体子标题转换为三级 Markdown 标题。
- 支持多层 `section > strong > span` 结构及由 `<strong>` 提供的语义粗体。
- 排除带可见背景的徽标或导读标签，并继续保留普通整段加粗。

## 安装或升级

```bash
uv tool install --upgrade magicmd
# 或
pipx upgrade magicmd
# npm wrapper
npm install -g magicmd@0.7.13
```

验证 Python CLI：

# MagicMD v0.7.13

v0.7.13 fixes WeChat visual headings being converted to plain bold text when their hierarchy is expressed through nested `span` styles.

## WeChat Visual Headings

- Reads font size, color, and weight from descendants that cover the complete text of a standalone block.
- Converts visual section headings at 20px or larger to level-two Markdown headings.
- Converts bold 17–19px subheadings to level-three Markdown headings.
- Supports nested `section > strong > span` structures and semantic bold inherited from `<strong>`.
- Excludes badges and intro labels with visible backgrounds while preserving ordinary bold paragraphs.
